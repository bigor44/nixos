# Bigor's NixOS Configurations

This repository contains my personal NixOS configurations, managed with [Nix Flakes](https://nixos.wiki/wiki/Flakes) and structured using [Snowfall Lib](https://github.com/snowfallorg/lib). It serves as an "infrastructure as code" approach to managing my NixOS systems, ensuring reproducibility and maintainability.

## ✨ Features

*   **Declarative System Management**: All system configurations are defined in Nix, ensuring a reproducible environment across different machines.
*   **Flake-based**: Leverages Nix Flakes for robust dependency management and easy system deployment.
*   **Modular Design**: Organized using `snowfall-lib` into reusable modules for system settings, desktop environments, services, and home manager configurations.
*   **Dedicated Roles**: Configurable roles for different machine types (e.g., `desktop` for workstations, `homelab_master` for servers).
*   **Home Manager Integration**: Personal user environment configurations (dotfiles, packages) are managed declaratively with [Home Manager](https://github.com/nix-community/home-manager).
*   **NixVim Integration**: Vim configurations are managed using [NixVim](https://github.com/nix-community/nixvim).
*   **Custom Options API**: A structured way to enable and configure features using a custom `bigor` namespace.

## 🚀 Getting Started

To use these configurations, you'll need NixOS with Flakes enabled.

### 1. Clone the Repository

```bash
git clone https://github.com/bigor/nixos.git # Replace 'bigor' with your actual GitHub username
cd nixos
```

### 2. Configure Your Host

This repository is set up to manage multiple hosts. You'll need to define your specific machine in the `systems/` directory.

*   **Example for `grospc`**:
    *   The `systems/x86_64-linux/grospc/default.nix` file defines the configuration for a desktop workstation named `grospc`.
    *   You would create a similar file for your own machine, adjusting the `networking.hostName` and other hardware-specific settings.

### 3. Apply the Configuration

Once your host is defined, you can switch to the new configuration:

```bash
# To apply the configuration for the current machine based on its hostname
sudo nixos-rebuild switch --flake .

# Alternatively, specify a particular host defined in the 'systems/' directory
sudo nixos-rebuild switch --flake .#yourhostname # e.g., sudo nixos-rebuild switch --flake .#grospc
```

## 📂 Repository Structure

The project follows a structure enforced by `snowfall-lib`:

```

│   └── x86_64-linux/

└── treefmt.toml            # Code formatter configuration
```

## ⚙️ Custom Configuration Options

A custom options API is defined in `modules/nixos/core/options.nix` under the `bigor` namespace, allowing for easy feature toggling and configuration:

*   `bigor.roles.desktop`: Set to `true` to enable a full graphical desktop environment, including audio (Pipewire), fonts, and GUI applications.
*   `bigor.roles.homelab_master`: Set to `true` for headless server services, container orchestration tools, etc.
*   `bigor.services.ssh.enable`: Enables OpenSSH daemon with hardened defaults.
*   `bigor.services.nfs.client` / `bigor.services.nfs.server`: Configure NFS client or server functionality.
*   `bigor.network.mainInterface`: Specify the primary network interface name.
